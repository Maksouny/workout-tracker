Недельный график

Суперсет = пара упражнений на противоположные группы мышц. Подход первого → 15-30 сек → подход второго → отдых 60-90 сек → повтор круга.

Профили

Профиль хранит свой формат тренировок, локацию и любимую группу мышц — свой график для каждого профиля.
