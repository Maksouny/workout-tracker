# Железо — модульная структура

Откройте `index.html` так же, как исходный файл.

## Структура

- `index.html` — только разметка страниц и подключение ресурсов.
- `css/styles.css` — все стили.
- `js/01-exercises.js` — база и редактирование упражнений.
- `js/02-schedule.js` — профили и генерация недельного графика.
- `js/03-workout-session.js` — пошаговая тренировка и таймер.
- `js/04-cooking-methods.js` — способы приготовления.
- `js/05-storage.js` — LocalStorage и журналы данных.
- `js/06-navigation.js` — переключение страниц и мобильное меню.
- `js/07-easter-egg.js` — пасхалка логотипа.
- `js/08-kbju.js` — расчёт КБЖУ.
- `js/09-meal-plan.js` — автоподбор рациона.
- `js/10-ingredients.js` — таблица ингредиентов.
- `js/11-units-popovers-tags.js` — единицы, всплывающие окна и теги.
- `js/12-dish-constructor.js` — конструктор блюд.
- `js/13-ratings-dishes.js` — рейтинги и список блюд.
- `js/14-reference.js` — справочник упражнений.
- `js/15-journal.js` — журнал тренировок.
- `js/16-paste-parser.js` — быстрый импорт записей из текста.
- `js/17-dashboard.js` — главная, графики и статистика.
- `js/18-export-import.js` — экспорт и импорт JSON.
- `js/19-init.js` — запуск приложения.

Порядок `<script>` в `index.html` важен: файлы пока используют общие глобальные функции и переменные исходного проекта.
